# Python 程序设计课堂记录

本仓库收录沈阳工业大学（SUT）《程序设计（引）》课程的 Python 课堂记录，由 SUT 教师在协助德比任课教师授课时记录和整理，供 2026 级同学课前预习、课后复习和动手练习参考。

内容以课堂代码示例、知识点说明和练习过程为主，按学期保存，主要使用 Jupyter Notebook（`.ipynb`）格式，部分学期另有 Python 脚本及配套文本文件。

## 学期入口

每个文件夹对应一个学期，名称中的 `1`、`2` 分别表示该学年的第一、第二学期。

| 学期 | 课堂记录 |
|---|---|
| 2026–2027 学年第一学期 | [2026-2027-1](2026-2027-1/) |
| 2025–2026 学年第一学期 | [2025-2026-1](2025-2026-1/) |
| 2024–2025 学年第一学期 | [2024-2025-1](2024-2025-1/) |
| 2023–2024 学年第一学期 | [2023-2024-1](2023-2024-1/) |
| 2022–2023 学年第二学期 | [2022-2023-2](2022-2023-2/) |

2026 级同学预习时，可以先从 [2025–2026 学年第一学期](2025-2026-1/)的记录开始，按日期阅读，再根据知识点查阅其他学期的示例。日期文件名通常采用 `YYYYMMDD` 格式，例如 `20251014.ipynb` 表示 2025 年 10 月 14 日的记录。

## 内容概览

现有记录涉及以下 Python 基础内容，各学期的记录范围和详略有所不同：

- 输入与输出、变量、数据类型、运算符和字符串。
- 条件判断、循环及相关练习。
- 列表、元组、集合和字典。
- 函数、参数、作用域、递归和模块。
- 文件读写、类与对象，以及随机数、绘图等示例。

`.ipynb` 文件将说明、代码和已保存的输出放在同一份记录中；`.py` 文件保存脚本或供其他示例导入的模块；`example.txt` 等文件用于文件读写练习。

## 阅读与运行

### 在线阅读

进入学期目录，点击 `.ipynb` 文件即可在 GitHub 上查看静态预览，包括说明、代码及已保存的输出。在线预览用于阅读，运行或修改代码需要使用 Notebook 环境。预览方式见 [GitHub 官方说明](https://docs.github.com/en/repositories/working-with-files/using-files/working-with-non-code-files#working-with-jupyter-notebook-files)。

### 本地练习

1. 在仓库页面选择 **Code → Download ZIP**，下载后解压；也可以使用 Git 克隆仓库。
2. 准备 Python 3 环境，并安装 Jupyter Notebook。已有可用环境的同学可以直接打开记录。
3. 从对应学期目录启动 Notebook，选择文件和 Python 3 内核，按顺序逐个运行相关代码单元格。

例如，在仓库根目录打开终端后执行：

```shell
python -m pip install notebook
cd 2025-2026-1
jupyter notebook
```

在打开的页面中选择一份记录，使用 `Shift + Enter` 运行当前单元格。安装与操作方法可参考 [Jupyter 安装说明](https://jupyter.org/install)和[代码运行说明](https://jupyter-notebook.readthedocs.io/en/stable/examples/Notebook/Running%20Code.html)。

运行时请留意：

- 使用 `input()` 的单元格需要按提示输入内容。
- 后面的单元格可能依赖前面定义的变量或函数；重启内核后，需要重新运行相关定义。
- 涉及 `calculator.py` 或 `example.txt` 的示例，应保留同一学期的配套文件，并在该学期目录中运行。
- 文件读写示例可能修改 `example.txt`，练习前可先保留一份副本。
- 使用 NumPy、Matplotlib 等第三方库的示例，需要在当前 Python 环境中安装相应库。

## 学习建议与使用说明

预习时先阅读知识点和短小示例，尝试预测程序输出；复习时先独立完成练习，再对照记录检查思路。修改输入、条件或参数，观察结果如何变化，比只阅读已有输出更有助于理解程序。

这些材料保留了课堂记录的特点，部分内容包含报错示例、调试过程或被注释的代码。请结合上下文逐步阅读和运行，遇到问题时自行检查语法、数据类型和执行顺序，并向教师提问。

课堂记录用于辅助学习。往学期记录中的教学进度、作业及考核信息反映当时的课程情况；当前课程安排与考核要求以当学期任课教师发布的信息为准。
